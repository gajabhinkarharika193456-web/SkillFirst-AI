# SkillFirst AI - System Architecture

## Project Overview

SkillFirst AI is a voice-first AI platform that identifies,
assesses and matches practical skills with suitable jobs
and calculates recommended remuneration.

## Main Users

1. Worker
2. Customer

## Worker Flow

Worker Registration
        ↓
Voice Skill Declaration
        ↓
Speech-to-Text
        ↓
AI Skill Extraction
        ↓
AI Skill Assessment
        ↓
Skill Score
        ↓
Job Matching
        ↓
Work Completion
        ↓
Customer Confirmation
        ↓
Remuneration Calculation
        ↓
Payment Initiation

## Customer Flow

Customer Registration
        ↓
Create Job
        ↓
Describe Problem
        ↓
Select Location
        ↓
Select Urgency
        ↓
AI Finds Suitable Worker
        ↓
Book Worker
        ↓
Work Completion
        ↓
Confirm Work
        ↓
Payment
        ↓
Rating

## AI Components

- Speech-to-Text
- Skill Extraction
- Skill Assessment
- Skill Scoring
- Job Matching
- Remuneration Recommendation

## Technology Stack

Frontend: HTML, CSS, JavaScript

Backend: Python, FastAPI

Database: MySQL

AI: Speech-to-Text + LLM/NLP

Version Control: Git and GitHub
